# Labasni (Android)

Application Android native du projet Labasni, construite avec Kotlin et Jetpack.

</div>

## Aperçu

- Architecture modulaire basée sur Android Jetpack.
- Support Kotlin Coroutines/Flows pour la logique asynchrone.
- Navigation et ressources configurées pour une distribution Play Store.

## Prérequis

- Android Studio Koala (ou version plus récente).
- JDK 17 configuré dans `JAVA_HOME`.
- SDK Android avec API 34 installé.

## Démarrage rapide

1. Cloner le dépôt.
2. Ouvrir le dossier `Labasni-Android` dans Android Studio.
3. Synchroniser Gradle puis exécuter la configuration `app`.

## Tests

```bash
./gradlew testDebugUnitTest
```
